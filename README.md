# Checkpoint Games

Blog acadêmico sobre o universo dos games, desenvolvido com HTML5, CSS3 e JavaScript puro.

## Páginas
- `index.html` — Home e conteúdos em destaque
- `hardware.html` — Hardware e montagem de setup
- `reviews.html` — Critérios de análise de jogos
- `esports.html` — Cenário competitivo e e-sports
- `contatos.html` — Informações e formulário demonstrativo

## Como visualizar
Abra o arquivo `index.html` em um navegador. Para testar como um site, também é possível iniciar um servidor local na pasta:
```bash
python -m http.server 8000
```
Depois acesse `http://localhost:8000`.

## Publicar gratuitamente no GitHub Pages
1. Crie ou entre em sua conta no GitHub.
2. Crie um repositório público, por exemplo `checkpoint-games`.
3. Envie todos os arquivos e a pasta `assets` deste projeto para a raiz do repositório.
4. No repositório, acesse **Settings > Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)` e salve.
7. Aguarde a publicação. O GitHub mostrará o endereço público do site na seção Pages.

## Observações
- O site possui cinco páginas e a navegação principal é mantida em todas elas.
- As imagens são ilustrações SVG locais criadas para este projeto.
- O formulário de contato é demonstrativo: valida os campos no navegador, mas não transmite mensagens a um servidor.
- A fonte do Google Fonts depende de conexão com a internet; há fontes alternativas no CSS.
